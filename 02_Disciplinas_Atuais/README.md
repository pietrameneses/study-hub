# 02 — Disciplinas Atuais

Material das disciplinas que curso no semestre 2026/2 (27/07 a 18/12/2026), agrupado por período.

| Período | Disciplinas |
|---|---|
| 1º | Bootcamp I |
| 4º | Algoritmos e Estruturas de Dados, Análise e Projetos de Sistemas, Gestão de Projetos, Integração DevOps |
| 5º | Bootcamp III, Desenvolvimento Mobile, Linguagens Formais e Autômatos |

Toda disciplina segue o mesmo padrão interno: `Atividades_e_Entregas/` para o que foi entregue e avaliado, e `Anotacoes_e_Resumos/` para material de estudo.

O agrupamento por período existe porque as oito disciplinas deste semestre pertencem a três períodos diferentes — sem essa camada, a listagem viraria uma lista solta sem hierarquia.
